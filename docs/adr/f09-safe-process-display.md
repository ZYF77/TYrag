# ADR：F09 公开过程只来自代码认可的阶段

- 状态：Accepted（用户已授权实施），2026-09-21。
- 背景：原始模型 reasoning 被原样转发和持久化；日志可能含问题、证据和模型输出。
- 决策：保留现有字段，固定白名单提示；不采用模型生成摘要。历史通过内部格式标记区分，未标记的 reasoning 不公开。企业调用上下文从 logging record 和模型 tracing 入口截断敏感数据。
- 替代方案：仅前端折叠或字符串脱敏不能阻止网络/历史泄露；全面删除字段会破坏既有客户端，因此不选。
- 代价：进度粒度降低，日志排错细节减少。既有诊断计数与错误位置继续提供运维依据。
- 上游边界、测试、回滚和重放见 [变更登记](../../patches/CHANGE-REQUEST-F09-SAFE-PROCESS.md)。生产配置与 Workflow DSL 不变。
