# ADR-001 文档引擎默认选择

- 状态：Accepted as default
- 日期：2026-08-04

## 背景
RAGFlow 官方主部署默认使用 Elasticsearch，并支持切换 Infinity。项目旧方案曾计划 Qdrant，但 RAGFlow 官方当前未将其作为标准文档引擎。

## 决策
MVP 使用 Elasticsearch。Infinity 只能在 ARM、资源、许可或性能评测后通过新 ADR 改选。Qdrant 不进入基线。

## 理由
- 最大化原生解析、metadata、全文、向量、Chat 和引用兼容；
- 降低上游升级冲突；
- 避免重写文档写入、查询、删除、过滤和高级功能。

## 回滚/变更
切换文档引擎视为数据迁移项目，必须在隔离环境重建索引和重新评测，不能原地改配置后继续使用旧数据。
