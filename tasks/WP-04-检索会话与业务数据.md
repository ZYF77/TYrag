# WP-04 检索、会话、业务 PG 与综合回答

## Owner
Retrieval/Business Data Agent

## 目标
实现查询分类、RAGFlow Chat/Session 适配、设备上下文、业务 Query Adapter、文档与业务记录聚合、SSE 和统一引用。

## 依赖
依赖 WP-00 契约、WP-01 ACL 接口、业务 PG 只读账号和表说明。

## 交付物
- `enterprise/gateway/query`；
- `enterprise/adapters/business_db`；
- conversation 映射；
- SSE 转换；
- 统一 citation；
- 综合问题 E2E。

## 验收
- 文档/业务/混合路由正确；
- 业务查询参数化、只读、限时限行；
- 会话不串用户；
- 设备上下文可切换；
- 无证据拒答；
- 来源分开展示。

## 禁止修改/禁止范围
不得自由 Text-to-SQL；不得让 LLM 直连生产库；不得使用未公开 API 参数作为长期合同。

## 完成报告
列出修改文件、测试命令、结果、契约变化、上游补丁、风险和后续集成注意事项。
