# WP-03 解析 Profile、图片表格和质量门禁

## Owner
Parsing Agent

## 目标
基于 RAGFlow 原生 parser/ingestion pipeline，为真实扫描、数字、混合 PDF 建 profile、测试集和质量门禁；实现文档级复核状态。

## 依赖
依赖 WP-00 固定版本和真实脱敏样本；模型端点由 Lead 配置。

## 交付物
- parser profile 配置；
- 测试夹具和解析评估脚本；
- 质量状态转换；
- 图片/表格/流程图引用验证；
- 复核 API 需求变更请求。

## 验收
- 三类 PDF 可处理；
- 图片表格引用可打开；
- 低质量不静默 ready；
- 加密/损坏/超限错误稳定；
- 不重写通用解析引擎。

## 禁止修改/禁止范围
不得自建整套 pdfplumber/pypdfium2/OCR 主链路；不得修改文档引擎；不得引入视觉向量。

## 完成报告
列出修改文件、测试命令、结果、契约变化、上游补丁、风险和后续集成注意事项。

## 执行基线（TYrag WP-03 有效解析加固）

本工作包只修改 `enterprise/`、验收脚本和契约，不修改 RAGFlow 上游解析器或其
内部数据库。实现必须使用 RAGFlow v0.26.4 public API：

1. profile 由 MIME/扩展名安全选择：PDF 使用 `pdf_deepdoc_v1`（`naive`、
   `layout_recognize=DeepDOC`）；图片使用 `image_picture_v1`；CSV/XLS/XLSX
   使用 `tabular_table_v1`。PDF 的业务类别只决定质量维度是否适用，不能把整份
   PDF 路由为 picture/table。
2. 上传后、解析前执行 PATCH→GET readback，并保存 `selected/configured`；解析
   终态 GET 保存 `executed` 或 `mismatch`。历史无证据版本标记
   `legacy_unverified`。
3. 新版本质量 `passed` 前不切 `current_version`，旧版本继续可用；晋级采用
   “启用新版本→SQLite 事务切 current→禁用旧版本”，失败可安全重试且不允许空窗。
4. 质量 gate 强制检查适用维度、expected tables/fields/citations、页码/坐标范围、
   多 positions、图片/表格资产和引用版本；缺证据不得 false pass。
5. 流程图仅在 RAGFlow 已检测到 figure crop 且有可验证证据时执行选择性 VLM；没有
   crop/图结构证据时保持 `review_required`，不得在 enterprise 伪造第二套解析器。

## 验收保证（机械门禁）

统一入口为 `enterprise/scripts/run_enterprise_tests.ps1`，profiles 为
`Contract / P0 / Integration / WP03 / All`。退出码固定为：`0` 通过，`1` 测试或
断言失败，`2` 缺真实样本/正式验收被阻断，`3` 依赖或外部环境不可用，`4` runner、
JUnit 或 RAGFlow tree guard 失败。任何 skip、xfail、xpass、缺失或空 JUnit 均失败。

正式 WP-03 需要脱敏人工复核样本：S1–S6、S8 各 2 份，S7a 旋转页和 S7b 低质量页
各 1 份（至少 16 份 PDF），并完成至少 50 个检索/引用问题。硬门包括：正常页覆盖
100%、无越界页；position 覆盖 ≥95%；设备/资产/故障标识 100%；OCR CER ≤5%；
表格/图片/图示召回 100%；表格关键单元格 100%；流程图关键节点/边/条件/警告
100%；引用页码/版本 100%；文本引用区域相交且包含目标中心，表格/图片 bbox IoU
≥0.5；Recall@8 ≥80%；无权限泄漏为 0；无答案拒答 ≥90%。S7b 必须
`review_required`，不能被整体通过掩盖。

每次正式运行必须写入 `artifacts/wp03/reports/<run_id>/`，至少包括环境和 git
状态、样本 manifest/hash、parser application/readback、文档/页/chunk/资产、查询
与引用、生命周期/安全负向、JUnit、汇总和文件 hash。日志不得包含完整正文、Prompt、
模型响应、Token 或客户敏感数据。PostgreSQL 当前仅有配置没有 Enterprise repository
调用链，runner 必须输出 `not_applicable` 证据，不能用空 smoke 宣称覆盖。
