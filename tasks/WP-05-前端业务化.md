# WP-05 业务化前端

## Owner
Frontend Agent

## 目标
实现普通用户问答、历史、设备上下文、引用抽屉、PDF/图片/表格证据，以及维护员同步和复核页面。

## 依赖
依赖冻结 OpenAPI；后端未完成时使用 MSW/Mock。

## 交付物
- `enterprise/web`；
- 角色路由；
- SSE 客户端；
- 引用和文件预览；
- 状态/错误展示；
- E2E。

## 验收
- 普通用户看不到高级配置；
- 401/403/404 不泄漏资源；
- 引用打开前重新鉴权；
- 真实状态不伪造百分比；
- SSE 断连正确。

## 禁止修改/禁止范围
不得把 API Key、对象键或管理凭据放浏览器；不得以隐藏按钮替代权限；不得直接调用内部数据库服务。

## 完成报告
列出修改文件、测试命令、结果、契约变化、上游补丁、风险和后续集成注意事项。
