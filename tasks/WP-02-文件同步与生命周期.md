# WP-02 文件同步、幂等和生命周期

## Owner
File Sync Agent

## 目标
实现文档事件接收、对象校验、SHA256、外部映射、RAGFlow 注册/解析跟踪、版本切换、停用和状态回写。

## 依赖
依赖 WP-00 契约、对象存储访问方式和 RAGFlow 文档 API/Connector 结论。

## 交付物
- `enterprise/gateway/sync`；
- 对象存储和 RAGFlow 适配器；
- 外部映射表迁移请求；
- 重试和对账任务；
- 幂等、版本和删除测试。

## 验收
- 10 次重复事件只产生一套有效结果；
- 新版 ready 前旧版可用；
- disable 后检索和文件不可用；
- 状态不误报；
- 失败可重试且不产生重复知识版本。

## 禁止修改/禁止范围
不得直接写 RAGFlow DB/文档引擎；不得假设共享路径零拷贝；不得物理删除旧对象。

## 完成报告
列出修改文件、测试命令、结果、契约变化、上游补丁、风险和后续集成注意事项。
