# WP-06 部署、安全、审计和备份

## Owner
Platform Agent

## 目标
实现部署 overlay、Secret、网络隔离、健康检查、基础指标、审计存储、备份和恢复演练脚本。

## 依赖
依赖 WP-00 固定版本和生产环境约束。

## 交付物
- `deploy/overlays`；
- 环境模板；
- 端口和网络测试；
- 审计 schema 请求；
- backup/restore drill；
- version manifest。

## 验收
- 默认只暴露业务入口；
- 无默认密码；
- volume 重启不丢数据；
- 备份离开容器并有 hash；
- 恢复演练可复核；
- 日志无密钥和完整正文。

## 禁止修改/禁止范围
不得修改上游 Compose 基线而不保留 overlay；不得执行递归危险删除；不得把 Docker volume 宣称为备份。

## 完成报告
列出修改文件、测试命令、结果、契约变化、上游补丁、风险和后续集成注意事项。
